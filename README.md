# Weekly Timecard Calculator

A web application that calculates total weekly work hours based on daily clock-in and clock-out times, with an optional lunch break toggle.

## Project Overview

This project was built to solve a simple, real-world problem: quickly figuring out how many hours you worked in a week without manually adding everything up.

Users enter their in and out times for each day, optionally include a lunch break, and the app calculates the total hours worked for the week.

This was built as part of my journey into software engineering through hands-on projects.

## Tech Stack

- JavaScript  
- HTML  
- CSS  
- Node.js  

## Features

- Enter clock-in and clock-out times for each day  
- Optional lunch break toggle  
- Automatic calculation of total weekly hours  
- Clean and simple user interface  

## Running the Project Locally

1. Clone the repository:
git clone https://github.com/Austin2414/Timecard-Calculator.git
 
2. Navigate into the project folder:
cd Timecard-Calculator

3. Install dependencies:
npm install

4. Start the app:
npm start

5. Open the provided local URL in your browser.
